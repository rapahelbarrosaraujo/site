Windows 1.0 (1985) – Primeira versão com interface gráfica baseada em janelas.

O Windows 1.0, lançado pela Microsoft em 20 de novembro de 1985, foi a primeira versão do sistema operacional Windows. Era, essencialmente, uma interface gráfica bidimensional para o MS-DOS, permitindo que os usuários interagissem com o sistema através de janelas e ícones.

Windows NT 4.0 (1996) – Voltado para empresas, com interface parecida com o 95.

Windows NT 4.0 (codinome Cairo) é a quarta versão do sistema operacional Microsoft Windows NT, lançado em 1996. É um sistema Windows de 32 bits disponível para estações de trabalho e servidores com interface gráfica semelhante ao Windows 95. Embora oferecesse maior estabilidade do que o Windows 95, era menos flexível do ponto de vista de um computador desktop. Grande parte da estabilidade foi alcançada graças à virtualização do hardware e aos aplicativos que acessavam o sistema através das APIs em vez de usar diretamente o hardware como era feito no MS-DOS, uma prática que continuou com o Windows 95. O uso de APIs em vez do uso direto do hardware exige muito mais trabalho do computador, e alguns aplicativos, como jogos, que fazem uso significativo do hardware, são executados mais lentamente. Embora a maioria dos programas escritos para a API Win32 funcione da mesma forma no Windows 95 e no Windows NT, o suporte insuficiente ao DirectX faz com que a maioria dos jogos 3D não funcione.[4]

Windows 2000 (2000) – Muito usado em servidores, foi base para o XP.

O Microsoft Windows 2000 foi um sistema operacional preemptivo, gráfico e de fácil aprendizagem que foi desenvolvido para trabalhar com um ou mais processadores de 32 bits em computadores na arquitetura x86 e 64 bits na arquitetura IA64. É parte de uma linha de sistemas operacionais denominada Microsoft Windows NT e foi lançado em 17 de fevereiro de 2000, sendo o sucessor do Windows NT 4.0. Ele está disponível em quatro versões: Professional, Server, Advanced Server e Datacenter Server

Windows 8 (2012) – Foco em telas sensíveis ao toque Mudança polêmica no Menu Iniciar.

O Windows 8, lançado em 2012, foi uma versão controvérsio do sistema operacional Windows NT da Microsoft, introduzindo mudanças significativas na interface, incluindo a Tela Iniciar e os aplicativos "Metro" (mais tarde renomeados para aplicativos da Plataforma Universal do Windows). A substituição do menu Iniciar e a interface Aero foram alvo de críticas, enquanto o Windows 8.1, lançado em 2013, ofereceu uma atualização gratuita e o Windows 10, lançado em 2015, reintroduziu o menu Iniciar, sendo geralmente bem-recebido. Principais mudanças e características: Tela Iniciar: Substituiu o tradicional menu Iniciar por uma interface de tela cheia com "live tiles" (telas interativas), que eram uma característica do Windows Phone. Aplicativos "Metro": Introduziu aplicativos de tela cheia que se assemelhavam à interface do Windows Phone, voltados para dispositivos touch e mais rápidos para iniciar. Remoção da interface Aero: A interface Aero clássica, com efeitos de transparência e visualização 3D, foi substituída por uma interface mais plana e colorida, similar à interface dos dispositivos móveis. Charms Bar: Foi introduzido um elemento de interface do usuário chamado Charms Bar, que oferecia opções de configurações e acesso a ferramentas do sistema. Internet Explorer 10: Incluiu o Internet Explorer 10, com um visual simplificado e mais rápido, especialmente na nova interface. Críticas e controvérsias: Muitos usuários criticaram a Tela Iniciar e a interface "Metro" por serem confusas e difíceis de usar, especialmente para usuários acostumados com o menu Iniciar. A remoção do menu Iniciar e a interface Aero geraram críticas de quem preferia a interface tradicional. A mudança de foco para dispositivos touch e a ênfase nos aplicativos "Metro" deixaram alguns usuários insatisfeitos, especialmente aqueles que usavam computadores de mesa. Debian 1993

Debian (/ˈdɛbiən/),[3][4] também conhecido como Debian GNU/Linux,[5] é uma distribuição Linux feita de software livre e de código aberto e software proprietário na forma de blobs[6][7] desenvolvida e mantida oficialmente pelo Projeto Debian, estabelecido por Ian Murdock em 16 de agosto de 1993.[8] Sua primeira versão (0.01) foi lançada em 15 de setembro de 1993,[9] com sua primeira versão estável (1.1) lançada em 17 de junho de 1996.[10]

Ubuntu 2004

Ubuntu é um sistema operacional(pt-BR) ou sistema operativo(pt-PT?) composto de software livre e de código aberto e de software proprietário na forma de blobs[6], construído a partir do núcleo Linux, baseado no Debian e utiliza GNOME como ambiente de desktop de sua mais recente versão com suporte de longo prazo (LTS). Esta distribuição Linux é desenvolvida pela Canonical Ltd.[7]

Fedora 2003

Fedora (conhecido como Fedora Core antes da versão 7) é um sistema operacional(pt-BR) ou sistema operativo(pt-PT?) Linux. O sistema operacional Fedora Linux é software livre e de código aberto, e os programas disponíveis dentro de seu repositório de programas também são programas livres que aderem a uma licença livre.

Red Hat Enterprise Linux (RHEL) 2000

Red Hat Enterprise Linux ( RHEL ) é uma distribuição Linux comercial de código aberto [ 6 ] [ 7 ] [ 8 ] desenvolvida pela Red Hat para o mercado comercial . O Red Hat Enterprise Linux é lançado em versões de servidor para x86-64 , Power ISA , ARM64 e IBM Z e uma versão desktop para x86-64. Fedora Linux e CentOS Stream servem como suas fontes upstream . Todo o suporte e treinamento oficial da Red Hat, junto com o Programa de Certificação Red Hat , se concentra na plataforma Red Hat Enterprise Linux. A primeira versão do Red Hat Enterprise Linux a ostentar o nome chegou originalmente ao mercado como "Red Hat Linux Advanced Server". Em 2003, a Red Hat renomeou o Red Hat Linux Advanced Server para "Red Hat Enterprise Linux AS" [ 11 ] e adicionou mais duas variantes, Red Hat Enterprise Linux ES e Red Hat Enterprise Linux WS. CentOS (descontinuado como conhecíamos, mas ainda relevante historicamente)

O CentOS, abreviação de Community ENTerprise Operating System, é uma distribuição Linux de classe corporativa derivada de códigos fonte gratuitamente distribuídos pela Red Hat Enterprise Linux e mantida pelo CentOS Project. A numeração das versões é baseada na numeração do Red Hat Enterprise Linux. Por exemplo, o CentOS 4 é baseado no Red Hat Enterprise Linux 4. A diferença básica entre um e outro é o fornecimento de suporte pago na aquisição de um Red Hat Enterprise Linux. Em termos de funcionalidade, podem ser considerados sistemas clones.

Linux Mint é uma distribuição Linux irlandesa. Possui duas versões: uma baseada em Ubuntu (com o qual é totalmente compatível e partilha os mesmos repositórios) e outra versão baseada em Debian. Suporta muitos idiomas, incluindo a língua portuguesa, e utiliza o Cinnamon como seu principal ambiente de desktop. É um sistema operacional moderno, elegante e confortável, que é poderoso e fácil de usar"; possui suporte da mídia pronto para o uso, incluindo alguns softwares proprietários; e vem com uma variedade de aplicativos gratuitos e de código aberto.[3][4][5]

Arch Linux

Arch Linux, ou Arch (pronúncia em inglês: [ɑːrtʃ]),[3] é uma distribuição Linux para computadores com arquitetura x86-64. Desenvolvido inicialmente pelo canadense Judd Vinet, esse sistema operacional se apresenta de maneira diferente de outros, como Windows e MacOS. Além de ser composto predominantemente por software livre e de código aberto, ele envolve contribuições da comunidade. O desenvolvimento é focado na elegância, minimalismo e simplicidade no código, e espera que o usuário faça alguns esforços para compreender o modo de funcionamento do sistema. O gerenciador de pacotes, Pacman, foi escrito especialmente para o Arch Linux e é usado para instalar, remover, pesquisar e atualizar os pacotes do sistema.

Kali Linux

Kali Linux é uma distribuição GNU/Linux baseada no Debian, considerado o sucessor do Back Track.[1] O projeto apresenta várias melhorias, além de mais aplicativos. É voltado principalmente para auditoria e segurança de computadores em geral. É desenvolvido e mantido pela Offensive Security Ltd.[2] Desde 21 de janeiro de 2016, é uma distribuição "rolling-release".[3] O Kali Linux dispõe de numerosos softwares pré-instalados, incluindo o Nmap (port scanner), Wireshark (um sniffer), John the Ripper (crackeador de password) e Aircrack-ng (software para testes de segurança em Rede de computadores.[1][4] O sistema pode ser utilizado a partir de um Live CD ou live-usb, além de poder ser instalado como sistema operacional principal. É distribuído em imagens ISO compilados para as arquiteturas x86, x64 e ARM.[5] O sistema chegou a aparecer em séries de televisão, no caso, Mr. Robot.[6]

Mac OS X 10.4 – Tiger (2005)

O Mac OS X 10.4 "Tiger", foi o quinto lançamento do Mac OS X. O Tiger foi liberado ao público em 29 de abril de 2005 como o sucessor do Mac OS X 10.3 "Panther", que foi lançado 18 meses antes, sendo substituido pelo Mac OS X 10.5 "Leopard", em 26 de outubro de 2007, após 30 meses, tornando-se o Mac OS X de mais longa versão. Alguns dos novos recursos incluem um rápido sistema de busca chamado Spotlight, uma nova versão do navegador Safari, Dashboard, um novo tema unificado, e suporte aperfeiçoado para uso em processadores 64 bits. O Tiger foi também a primeira versão do sistema operacional Mac OS X liberado para trabalhar em computadores Apple Inc. com arquitetura Intel (computadores Apple usando processadores x86). Seis semanas após o seu lançamento oficial, a Apple tinha entregue 2 milhões de cópias do Tiger, o que representava 16% de todos os usuários do Mac OS X. A Apple afirmou na época que o Tiger foi o mais bem sucedido Mac OS X da história da empresa. Na Conferência WWDC, em 11 de junho de 2007, o CEO da Apple, Steve Jobs anunciou que, dos 22 milhões de usuários do Mac OS X, mais do que 67% estavam usando a versão Tiger.

Mac OS X 10.5 – Leopard (2007)

O Mac OS X Leopard (versão 10.5) é o sexto grande lançamento do macOS , o sistema operacional de desktop e servidor da Apple para computadores Macintosh . O Leopard foi lançado em 26 de outubro de 2007 como sucessor do Mac OS X Tiger e está disponível em duas edições: uma versão desktop adequada para computadores pessoais e uma versão de servidor , o Mac OS X Server . Ele era vendido por US$ 129 [ 2 ] para a versão desktop e US$ 499 para o Server. [ 8 ] O Leopard foi substituído pelo Mac OS X Snow Leopard (versão 10.6) em 2009. O Mac OS X Leopard é a última versão do macOS que suporta a arquitetura PowerPC , já que seu sucessor, o Mac OS X Snow Leopard, funciona apenas em Macs baseados em Intel .

Mac OS X 10.7 – Lion (2011)

Mac OS X v10.7 "Lion" é uma das versões do sistema operacional Mac OS X da Apple Inc., sendo o sucessor do Snow Leopard e antecessor do Mountain Lion, e foi lançado mundialmente em 20 de Julho de 2011 através da Mac App Store. Entre as novidades, inclui o Launchpad, recursos inspirados no iPad, aplicativos em tela cheia, barras autoescondidas, Mission Control, entre outros. É a última versão a ser chamada oficialmente de "Mac OS X".

macOS 10.10 – Yosemite (2014)

macOS 10.10 Yosemite foi a décima primeira versão principal do macOS (anteriormente OS X), lançado pela Apple em 2014. Foi anunciado na WWDC de 2014 e lançado para todos os usuários de Mac em 16 de outubro de 2014, por download na App Store. O Yosemite trouxe uma mudança visual, com uma interface mais moderna e plana, e também melhorias de desempenho e segurança.

O Catalina foi anunciado na WWDC 2019 em junho de 2019 e foi lançado ao público em outubro do mesmo ano.
