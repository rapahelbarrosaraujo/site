1.1 Componentes internos

Componentes internos referem-se às peças que estão dentro do gabinete de um computador e são essenciais para o seu funcionamento. São componentes como a placa-mãe, o processador, a memória RAM, o armazenamento (HD ou SSD), a fonte de alimentação, entre outros. Estes componentes trabalham juntos para processar informações, armazenar dados e interconectar outros dispositivos.

1.1.1 CPU

CPU é a sigla para Central Process Unit, ou Unidade Central de Processamento. Ele é o principal item de hardware do computador, que também é conhecido como processador. A CPU é responsável por calcular e realizar tarefas determinadas pelo usuário e é considerado o cérebro do PC

1.1.2 Armazenamento

O armazenamento de computador refere-se aos componentes que guardam dados a longo prazo, permitindo que o usuário acesse e utilize a informação mesmo após o desligamento do computador. Diferentemente da memória (RAM), que é volátil, o armazenamento é não volátil. Os dispositivos de armazenamento mais comuns incluem discos rígidos (HDD) e unidades de estado sólido (SSD).

1.1.3 Memória

A memória de um computador é essencial para o armazenamento temporário e rápido de dados e instruções, permitindo que o computador execute tarefas rapidamente. A memória RAM (Random Access Memory) é o tipo de memória mais comum em computadores, onde os dados são armazenados enquanto o computador está em funcionamento e perdidos quando o computador é desligado.

1.1.4 Fonte de alimentação

Uma fonte de alimentação funciona convertendo energia de uma tomada de parede e roteando essa energia para cada um dos componentes individuais em seu sistema, por meio de uma variedade de cabos

1.2 Componentes externos

Os componentes externos de um PC, também conhecidos como periféricos, são dispositivos que permitem ao utilizador interagir com o computador ou que são utilizados para exibir ou armazenar dados. Exemplos incluem o monitor, o teclado, o rato, a impressora e os alto-falantes.

1.2.1 Teclado

Um dispositivo de entrada utilizado para digitar texto e comandos.

1.2.2 Monitor de vídeo

Permite a visualização da informação processada pelo computador.

1.2.3 Mouse

Um dispositivo de entrada que permite a navegação e a seleção de elementos na tela.

1.2.4 Impressora

Um dispositivo de saída que permite a impressão de documentos.

1.2.5 Plotter

Um plotter, também conhecido como impressora de grande formato, é uma impressora especializada em criar desenhos e gráficos de grande tamanho, geralmente com alta qualidade e precisão. Eles são usados em diversas áreas como engenharia, arquitetura, cartografia e indústria gráfica, para imprimir projetos, plantas, mapas e muito mais.

1.2.6 Scanner

Dispositivo que permite digitalizar documentos e imagens.

1.2.7 Gabinete

é a caixa que abriga todos os componentes internos do computador, como a placa-mãe, processador, memória RAM, placa de vídeo, HD/SSD e fonte de alimentação. Ele serve para proteger esses componentes de danos, organizar os cabos e garantir a ventilação e refrigeração para evitar superaquecimento.

1.2.8 Web Cam

Uma webcam é uma câmara de vídeo que está, em regra, ligada diretamente a um computador. É um dispositivo de hardware de entrada de sinal (input), cuja função é a captação de imagem e vídeo.

1.2.9 Caixas de som

são essenciais para jogar, assistir filmes ou ouvir músicas no computador

1.2.10 Microfone

Dispositivo de entrada que permite a captura de áudio.

1.2.11 Head Set

Dispositivos de saída que permitem a audição de som.

1.3.1 Interfaces sem fio

Interfaces sem fio, também conhecidas como wireless, permitem a comunicação entre dispositivos eletrónicos sem fios físicos, como cabos ou fios. Utilizam tecnologias como Wi-Fi, Bluetooth, Zigbee, entre outras, para transmitir dados por ondas de rádio ou outros métodos de comunicação sem fio.

1.3.2 Áudio

écnica de gravação, transmissão e reprodução do som, assim como ao próprio som como um sinal elétrico ou um fenômeno físico

1.3.3 Rede (Ethernet)

uma tecnologia de rede de computadores com fio amplamente utilizada para conectar dispositivos em redes locais (LAN), redes metropolitanas (MAN) e redes de longa distância (WAN). Funciona transmitindo dados através de cabos de rede, garantindo uma comunicação segura e rápida entre os dispositivos conectados.

1.3.4 VGA

VGA é a sigla para "Video Graphics Array", um padrão de exibição de vídeo e tipo de conexão amplamente utilizado em computadores. Introduzido pela IBM em 1987, o VGA tornou-se o padrão gráfico padrão para PCs e lançou as bases para os monitores de computador modernos.

1.3.5 HDMI

DMI, que significa High-Definition Multimedia Interface (Interface Multimídia de Alta Definição), é um padrão de conexão universal usado para transmitir vídeo e áudio em alta qualidade entre dispositivos como televisores, computadores, consoles de jogos e outros aparelhos de entretenimento. Através de um cabo HDMI, é possível conectar estes dispositivos e transmitir conteúdo em alta definição, como 4K e 8K, além de áudio de alta qualidade.

1.3.6 USB

USB, sigla para Universal Serial Bus (Porta Serial Universal), é um padrão de conexão que permite a comunicação e transferência de dados entre dispositivos eletrônicos, como computadores, smartphones, tablets e periféricos. A USB também pode fornecer energia para dispositivos, como a recarga de um smartphone.
